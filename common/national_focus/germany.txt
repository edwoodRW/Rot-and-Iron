# STRUCTURE
# Phase 0 — THE GATHERING STORM (pre-war)
#   Germany has NOT yet invaded the USSR. The opening game
#   is spent building an alliance network, running a shadow
#   war against UBSR/Soviet interests, quietly rearming
#   without tipping Germany's hand, and securing Liebich's
#   domestic mandate for war.
# Phase 1 — THE WAR COUNCIL (war begins)
#   Once enough of Phase 0 is complete, "The Die Is Cast"
#   unlocks the war council, Germany commits to the
#   two-front invasion of the USSR, and the wartime branches
#   open up:
#   - War Economy mobilisation
#   - Cutting UBSR supply routes to the USSR (the Atlantic)
#   - Formalising the ally network (Scotland, France, China)
#   - Internal political pressure from Brandt's anti-war left
###########################################################
